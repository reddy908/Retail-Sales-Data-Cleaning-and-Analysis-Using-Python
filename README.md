# Retail Sales Data Cleaning and Analysis Using Python

## Project Overview
This project analyzes retail sales data using Python. The dataset contains data quality issues, including missing values, duplicate records, inconsistent text formats, invalid numerical values, and mixed date formats.

The objective is to clean the raw dataset, perform exploratory data analysis (EDA), visualize sales performance, and derive actionable business insights.

## Objectives
- Identify and handle missing values.
- Detect and remove exact duplicate records.
- Standardize text and date formats.
- Validate quantities, unit prices, discounts, and sales calculations.
- Analyze product, city, category, and monthly sales performance.
- Create visualizations to communicate findings.
- Recommend data-driven business actions.

## Tools and Technologies

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning Process
1. Inspected the dataset structure, columns, data types, and summary statistics.
2. Identified missing values and documented appropriate handling decisions.
3. Detected and removed exact duplicate records.
4. Standardized text values by removing extra spaces and correcting capitalization.
5. Converted order dates to datetime format.
6. Identified invalid quantities, unit prices, and discounts.
7. Recalculated sales amounts using validated inputs.
8. Exported the analysis-ready dataset to CSV.
